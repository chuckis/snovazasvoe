# Гайд по наполнению сайта на nsite-clay (портфолио + блог)

Коротко: это **nsite-clay** (шаблон CMS). Контент редактируется прямо на странице блоками, без отдельной админки.

## 1. Как войти в режим редактирования

1. Откройте сайт в браузере
2. Добавьте `#edit` в конец адреса URL: `https://ваш-сайт/#edit`
3. В нижней части экрана появится панель инструментов
4. Нажмите **`Sign in`** и войдите как владелец (NIP-07 расширение или NIP-46, например Amber/nsec.app)
5. После входа появятся кнопки владельца: `Add a block`, `Edit content`, `Write`, `Settings`, `History`, `Save`

**Готово.** Теперь можно редактировать страницу прямо на ней.

## 2. Два способа редактирования

У nsite-clay есть 2 удобных режима:

- **Прямо на странице** — кликаете по тексту (появляется курсор) и редактируете его. Удобно править заголовки, описания, подписи.
- **«Edit content» (Форма)** — кнопка в нижней панели. Открывает боковую панель со всеми полями сайта (заголовок, слоган, списки карточек и т.д.). Удобно, если хотите быстро заполнить много полей сразу, не лазая по блокам.

## 3. Шапка сайта (заголовок и слоган)

Верхняя часть — заголовок сайта и подзаголовок.

- **Заголовок** (`site title`) — кликаете прямо по нему на странице (однострочное редактирование) или заполняете в `Edit content → site title`
- **Слоган/подзаголовок** (`tagline`) — то же самое, короткая фраза о вас/проекте

## 4. Портфолио (проекты)

Лучший блок для портфолио — **Cards (Карточки)**. Он повторяемый: можно добавлять сколько угодно проектов.

### Как добавить проекты (блок Cards)

1. Внизу нажмите **`Add a block → Layout → Cards`** (или `▤ Cards`)
2. На странице появятся карточки. Кликните по заголовку каждой (`A card`) — напишите название проекта
3. Кликните по описанию — опишите проект (задача, стек, результат, что сделали)
4. У каждой карточки справа при наведении есть шестерёнка (rail): стрелки перемещают, `⧉` — дублирует, `✕` — удаляет
5. Внизу блока есть кнопка **`Add a card`** — добавляет ещё один проект

### Альтернативы для портфолио

- **`Picture` (Картинка)** — один скриншот/обложка проекта + подпись. Добавить: `Add a block → Media → Picture`
- **`Gallery` (Галерея)** — несколько фото/скриншотов проекта в сетке. У каждой картинки есть своя шестерёнка, можно добавлять/удалять фото
- **`Button` (Кнопка)** — ссылка на проект (демо, репозиторий). Текст кнопки редактируется прямо, ссылку можно поправить в режиме редактирования (выделить текст кнопки → вставить ссылку в тулбаре rich-text)

**Рекомендация:** для классического портфолио проще всего использовать **Cards** (3–6 проектов будет достаточно).

## 5. Блог

В nsite-clay блог делается двумя способами. Выбирайте один, в зависимости от задачи.

### Вариант А. Автоматический блог из Nostr (рекомендуется)

Ваши посты публикуются в Nostr (как события), а на сайте автоматически подтягиваются в блоке `Feed`.

**Когда подходит:** хотите, чтобы посты были видны не только на сайте, но и в Nostr-клиентах (Habla, Primal, njump и др.), а добавлять новые записи можно из любого Nostr-клиента или через `Write` на сайте.

**Как добавить ленту блога:**

1. Нажмите **`Add a block → Nostr → Nostr feed`** (⚡ Feed)
2. В появившемся блоке сверху можно отредактировать заголовок ленты (например `Блог`, `Статьи`, `Заметки`)

**Какие типы постов подтягивать:**

- **`articles` (kind 30023)** — длинные статьи (хорошо для блога). Заголовок + превью + ссылка на полную статью.
- **`notes` (kind 1)** — короткие заметки (твиты/мысли).

Чтобы блог тянул **только ваши посты**, публикуйте статьи через кнопку **`Write`** (в нижней панели) от вашего ключа.

### Вариант Б. Статичный блог (записи прямо на странице)

**Когда подходит:** хотите, чтобы блог был только на сайте, без публикации в Nostr.

**Как добавить отдельную запись блога:**

1. `Add a block → Text` — текст статьи
2. `Add a block → Heading` — заголовок статьи (перед текстом)
3. Можно добавить `Picture` (обложка статьи) перед заголовком

Для нескольких записей просто добавляйте такие блоки друг за другом (между ними в режиме редактирования появляются `+` для вставки новых блоков).

## 6. Как добавлять/удалять/перемещать блоки

У каждого блока при наведении мыши появляется **вертикальная полоса (rail)** справа:

- `↑/↓` (или ←/→) — переместить блок выше/ниже
- `⧉` — дублировать блок
- `⚙`/иконка — настройки блока (если есть)
- `✕` — удалить блок

Между блоками в режиме `#edit` появляются **плюсики (`+`)** — можно вставить новый блок прямо между существующими, без добавления в конец.

## 7. Работа с картинками

### Одиночная картинка (Picture)

1. `Add a block → Media → Picture`
2. Нажмите на серую заглушку-картинку → откроется выбор изображения
3. Можно **загрузить файл** (загрузится на Blossom) или **вставить URL**
4. Подпись редактируется прямо под картинкой (`Caption`)

### Галерея (Gallery)

1. `Add a block → Media → Gallery`
2. У первой картинки есть шестерёнка → `Choose the picture` (выбрать фото)
3. Кнопка **`Add a picture`** внизу блока — добавить ещё фото
4. У каждой фото можно двигать, дублировать, удалить

## 8. Быстрое заполнение через «Edit content»

1. Нажмите **`Edit content`** в нижней панели
2. Справа откроется форма с полями: `site title`, `tagline` и списками
3. Заполняйте поля — изменения сразу отображаются на странице
4. Закройте форму крестиком

## 9. Сохранение и публикация

Когда всё заполнили:

1. Нажмите **`Save`** (кнопка синяя внизу панели)
2. Страница сериализуется, файлы загрузятся в **Blossom**, подпишется Nostr-событие
3. После сохранения страница перезагрузится с новой версией

## 10. Чек-лист для портфолио + блога

- [ ] Шапка: название + короткий слоган
- [ ] Портфолио: 2–4 проекта в блоке **Cards** (название + описание + при необходимости кнопка-ссылка)
- [ ] О себе/описание: блок **Text** или **Lead**
- [ ] Блог: добавлен блок **Feed** (статьи `articles`) — если планируете писать в блоге
- [ ] Картинки: загрузили обложки/скриншоты
- [ ] Проверили в обычном режиме (без `#edit`) — всё смотрится аккуратно
- [ ] Нажали **Save** и перезагрузили страницу

## 11. Полезные советы

- **Один ключ — один владелец.** Редактировать может только владелец.
- **Блоки — ваша главная сила.** Если чего-то не хватает — добавьте новый блок через `+` или `Add a block`.
- **Для блога лучше использовать `articles` (kind 30023)**.
- **Посты можно писать прямо на сайте** через кнопку `Write`.
- **Сначала наполните текстом, потом сохраните один раз.**
