# План добавления просмотра 3D-моделей .STL на сайте nsite-clay

Коротко: **Да, можно**. Но не "из коробки" — нужно добавить новый блок и подключить вьювер для `.stl`.

## 1. Как это работает в nsite-clay
В этой системе всё строится на блоках (`<template nc:block>`) и на том, что на страницу можно добавлять JS/CSS. 

Смотреть `.stl` прямо в браузере можно через WebGL. Есть два рабочих варианта:

| Вариант | Размер | Удобство | Потребуется | Примечание |
|---|---|---|---|---|
| **[model-viewer](https://modelviewer.dev/)** (рекомендуется) | ~150-200 КБ (модульный) | Максимально просто. `camera-controls`, авто-поворот, зум, тапы на мобилке. Поддерживает `.stl`, `.glb`, `.gltf` | Подключить `model-viewer.min.js` | Самый быстрый путь под nsite-clay. Меньше всего JS писать руками |
| **[Three.js](https://threejs.org/) + STLLoader** | ~600-900 КБ + загрузчики | Больше контроля (камеры, освещение, выделение и др.) | `three.module.js`, `STLLoader.js`, `OrbitControls.js` | Гибче, но больше кода, сложнее встраивать в блок-шаблон |

Моё предложение — **начинать с `model-viewer`**.

## 2. Как вписать в текущий сайт

У nsite-clay блоки живут внизу `index.html` в `<template>`. Нужно добавить новый блок, например `model3d`.

Примерный шаблон блока:

```html
<template nc:block="model3d" nc:label="3D-модель" nc:icon="◈" nc:group="Media"
          nc:on-add="model" nc:hint="Загрузить .STL или указать ссылку">
  <section class="b-model3d">
    <model-viewer nc:slot
      src=""
      alt="3D-модель"
      auto-rotate
      camera-controls
      shadow-intensity="1"
      style="width: 100%; height: 420px; background: transparent;">
    </model-viewer>
    <p class="b-model3d-caption" editable="single-line">Подпись к модели</p>
  </section>
</template>
```

Что важно учесть:

- **Подключение библиотеки**. `model-viewer` нужно загрузить один раз. Логичнее всего добавить `<script type="module" src="/model-viewer.min.js"></script>` в `<head>` или перед `</body>`. Файл скачать локально и залить вместе с сайтом в Blossom (чтобы не зависеть от CDN).
- **Загрузка `.stl`**. У текущего пикера медиа в nsite-clay заточен под картинки/видео. Для `.stl` нужен либо простой ввод ссылки, либо расширить пикер, чтобы принимать `*.stl`. Вариант проще — позволить просто вставить прямую ссылку на `.stl` (можно загрузить сам `.stl` через тот же механизм загрузки в Blossom).
- **Стили**. Добавить CSS в блок `<style>` (как у остальных блоков). Например `height: min(70vh, 520px)` чтобы модель адекватно смотрелась на мобилке.
- **Редактируемость**. Сам `src` можно править через `Edit content` (добавить правило `".b-model3d model-viewer@src"`), либо просто редактировать в HTML. Для владельца оба варианта рабочие.
- **Без JS при чтении**. Если у читателя отключён JS, модель просто не отобразится. Это приемлемо для большинства портфолио-кейсов.

## 3. План внедрения (по шагам)

| Шаг | Действие | Заметка |
|---|---|---|
| **1.** | Скачать `model-viewer.min.js` | С официального npm/dist или с сайта modelviewer.dev. Взять минимальную сборку. |
| **2.** | Добавить скрипт в `index.html` | Подключить модульным скриптом. Убедиться, что грузится до появления блока. |
| **3.** | Добавить CSS для `.b-model3d` | Задать высоту, `max-width`, при желании фон/обводку. |
| **4.** | Добавить `<template nc:block="model3d"...>` | В блок-библиотеку внизу `index.html`. Повторить стиль остальных блоков. |
| **5.** | Расширить `nc:cms` (опц.) | Добавить поле `3D модель` с привязкой к `model-viewer@src` для удобства в форме `Edit content`. |
| **6.** | Протестировать | Загрузить `.stl` на Blossom/указать ссылку, проверить зум/вращение, мобилку, сохранение через `Save`. |
| **7.** | Задеплоить | Вместе со всем остальным каталогом через `npx nsite-clay deploy . ...` |

## 4. Риски и нюансы

- **Размер страницы.** `model-viewer` добавит ~200КБ. Доп. `.stl` может быть 1-10МБ. Blossom это потянет, но первые секунды загрузки на медленном интернете будут заметны.
- **Мобилка.** На слабых телефонах большие полигоны будут лагать. Иногда стоит упрощать модель перед заливкой.
- **Кросс-браузерность.** В современных браузерах работает, но очень старые IE не поддерживаются (неактуально для Nostr-аудитории).
- **"No CDN" философия.** Если положить `model-viewer.min.js` локально в проект и залить вместе с сайтом — соответствует принципам nsite-clay. Если подключать с `unpkg`/`jsdelivr` — нарушит идею "всё своё".
- **Расширение медиа-пикера.** Если очень хочется загружать `.stl` кнопкой как картинку — придётся чуть править `nsite-clay.js`. Проще и безопаснее сначала реализовать через прямую ссылку/локальную загрузку файла.

## Рекомендация

**Оптимальный минимальный вариант:** добавить блок с `model-viewer`, подключить `model-viewer.min.js` локально, загрузку `.stl` сделать через ввод ссылки (либо через обычную загрузку файла рядом с остальными ассетами). Этого достаточно для показа 3D-моделей в портфолио.

**Мой план действий, если приступать:** сначала добавить библиотеку + блок + стили в `index.html`, протестировать локально/на девнете, потом задеплоить. Никаких правок ядра (`nsite-clay.js/chrome`) не требуется для первого рабочего варианта.
